=====================================================
 GitHub Pages 자동 배포 - 사용법
=====================================================

이 폴더는 GitHub 저장소(260604hj/260604hj)와 연결되어 있습니다.
사이트 주소: https://260604hj.github.io/260604hj/

-----------------------------------------------------
 평소 작업 순서
-----------------------------------------------------

1. (선택) [최신버전_받기.bat] 더블클릭
   -> 다른 PC나 GitHub 웹에서 수정한 내용이 있으면 먼저 받아옵니다.
      이 PC에서만 작업한다면 건너뛰어도 됩니다.

2. 이 폴더 안의 파일(index.html 등)을 자유롭게 편집/저장합니다.

3. [배포.bat] 더블클릭
   -> 변경 내용이 자동으로 GitHub에 올라가고(commit + push),
      1~2분 뒤 위 사이트 주소에 반영됩니다.

끝! 이 두 가지만 기억하면 됩니다.

-----------------------------------------------------
 파일 설명
-----------------------------------------------------

 배포.bat            : 수정한 내용을 업로드 + 자동 배포
 최신버전_받기.bat   : GitHub의 최신 내용을 내려받기
 _deploy.ps1         : 배포.bat 이 사용하는 내부 스크립트 (건드리지 마세요)
 _pull.ps1           : 최신버전_받기.bat 이 사용하는 내부 스크립트

-----------------------------------------------------
 문제가 생기면
-----------------------------------------------------

- "push 실패" 메시지가 뜨면, 보통 다른 곳에서 먼저 수정한 경우입니다.
  -> [최신버전_받기.bat] 를 먼저 실행한 뒤 다시 [배포.bat] 실행.

- 배포했는데 사이트가 안 바뀌면 1~2분 기다린 뒤 브라우저 새로고침
  (Ctrl + F5) 하세요.
