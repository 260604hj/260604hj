STEP 1 · 받기

편집 전 — 최신본 받기 ⭐

🖱️ 「최신버전_받기.bat」 더블클릭
  • ✓
    다른 팀원이 바꾼 최신 내용을 먼저 받아옵니다.
  • !
    이걸 건너뛰면 작업이 충돌할 수 있어요. 편집 전 습관으로 만드세요.
STEP 2 · 수정 (1) 만들기

클로드에게 “만들어줘” 라고 하기

파일을 직접 짤 줄 몰라도 됩니다. 원하는 걸 말로 설명하면 클로드가 HTML을 만들어 줍니다.

클로드에게 이렇게 ↓ “260604hj 폴더의 miniapps 안에 ‘회의록’ 페이지를 새로 만들어줘. 날짜와 내용을 입력해 목록으로 보여주는 간단한 HTML로. 그리고 index.html 메뉴에 링크도 추가해줘.”

💡 “무엇을 / 어디에” 만들지 구체적으로 말할수록 결과가 정확합니다.

STEP 2 · 수정 (2) 고치기

클로드에게 “수정해줘” 라고 하기

이미 있는 화면을 바꾸고 싶을 때도 그냥 말하면 됩니다.

클로드에게 이렇게 ↓ “index.html 맨 위 제목을 ‘○○팀 업무 포털’로 바꾸고, 글씨를 더 크고 진하게 해줘. 배경은 흰색으로.”
  • ↺
    맘에 안 들면 그냥 다시 말하면 됩니다 — “버튼을 파란색으로 바꿔줘.”
  • ⚠
    오류가 나면 화면의 오류 메시지를 그대로 복사해 클로드에게 보여주세요.
STEP 3 · 올리기

웹에 올리기 (배포)

🖱️ 「배포.bat」 더블클릭
  • ✓
    바뀐 내용이 자동으로 깃허브에 올라갑니다.
  • ⏱
    1~2분 뒤 사이트에 반영됩니다. 검은 창에 “배포 완료!”가 뜨면 성공.

파일 관리

파일은 어디에 두나

260604hj/ ├─ index.html ← 메인 페이지 ├─ miniapps/ ← 기능(탭)별 페이지 ├─ IMG/ ← 이미지 모음 ├─ data/ ← 엑셀·csv 데이터 ├─ 배포.bat ← [버튼] 올리기 └─ 최신버전_받기.bat ← [버튼] 받기

이미지는 IMG/, 엑셀은 data/ 에 넣고 클로드에게 “이걸 화면에 넣어줘”라고 하면 됩니다. 파일을 추가·이동해도 마지막에 배포.bat만 누르면 그대로 반영됩니다.

꼭 지켜주세요

⚠️ 주의사항

🔴 이 창고는 “공개”입니다 — 올리면 전 세계에 공개돼요
비밀번호·개인정보·대외비·고객 데이터는 절대 올리지 마세요. 민감한 데이터는 로그인이 걸린 별도 서버에 저장해야 합니다(담당자 문의).
🔴 큰 파일은 올라가지 않습니다
한 파일이 100MB를 넘으면 거부됩니다. 대용량 원본(큰 PPT·CAD·동영상)은 따로 보관하고, 웹 이미지는 용량을 줄여서 넣으세요.

🟡 “push 실패”가 뜨면 → 「최신버전_받기.bat」 한 번 실행 후 다시 「배포.bat」.
