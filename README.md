# 📘 우리 팀 웹앱 — 작업 가이드 (비전문가용)

코딩을 전혀 몰라도 괜찮습니다. 이 문서대로만 따라 하면 누구나 우리 팀 웹앱을 **수정하고 인터넷에 올릴 수** 있습니다.

> 📑 **슬라이드로 보기(추천):** https://260604hj.github.io/260604hj/guide.html
> 우리 사이트 주소: **https://260604hj.github.io/260604hj/**

---

## 0. 한눈에 보는 큰 그림

용어 3개만 알면 됩니다.

| 말 | 쉽게 말하면 |
|----|-------------|
| **GitHub (깃허브)** | 우리 팀 **공용 파일 창고**. 여기 올린 파일은 자동으로 웹사이트가 됩니다. |
| **내 PC의 폴더** | 그 창고를 내 컴퓨터에 **복사해 둔 것**. 여기서 편집합니다. |
| **배포 (deploy)** | 내가 수정한 걸 창고로 **올려서 웹에 반영**하는 것. |

작업은 언제나 이 **3단계 반복**입니다:

```
 ①  받기   →   ②  수정   →   ③  올리기   →  (자동)  웹사이트 반영
 (최신본)      (클로드로)     (배포 버튼)         1~2분 뒤
```

**`집PC_세팅_클로드에게.txt` 파일의 내용을 그대로 복사해서 붙여넣으세요.**
나머지(프로그램 설치, 창고 복사)는 클로드가 알아서 해줍니다.

준비가 끝나면 바탕화면에 **`260604hj` 폴더**가 생기고, 그 안에 작업 파일과
**버튼(.bat 파일)들**이 들어 있습니다. 앞으로 모든 작업은 이 폴더 안에서 합니다.

> 로그인은 사람이 직접 해야 하는 단계가 한 번 있습니다. 반드시 우리 팀
> 계정 **`260604hj`** 로 로그인하세요. (클로드가 그 시점에 안내해 줍니다.)

## 2. 평소 작업 — 버튼 2개만 기억하세요

폴더 안에는 더블클릭으로 실행하는 버튼이 두 개 있습니다.

### ① 편집 전 → `최신버전_받기.bat` 더블클릭  ⭐꼭!
다른 팀원이 바꾼 **최신 내용을 먼저 받아옵니다.** 이걸 건너뛰면 충돌이 날 수 있어요.

### ② 수정 → 클로드에게 시키기
파일을 직접 못 고쳐도 됩니다. 클로드에게 부탁하세요. 예:
> "260604hj 폴더의 index.html에 '문의하기' 탭을 추가해줘."

### ③ 올리기 → `배포.bat` 더블클릭
바뀐 내용이 **자동으로 깃허브에 올라가고**, 1~2분 뒤 사이트에 반영됩니다.
완료되면 검은 창에 "배포 완료!"와 사이트 주소가 표시됩니다.

## 3. 파일은 어디에, 어떻게 두나

폴더를 이렇게 정리해서 쓰는 걸 권장합니다(없는 폴더는 만들면 됩니다):

```
260604hj/
├─ index.html             ← 메인 페이지
├─ miniapps/              ← 기능(탭)별 페이지 모음
├─ IMG/                   ← 이미지 모음
├─ data/                  ← 엑셀(xlsx), csv 등 데이터 파일
├─ 배포.bat               ← [버튼] 올리기
├─ 최신버전_받기.bat       ← [버튼] 받기
└─ README.md              ← 이 안내문
```

| 종류 | 어떻게 |
|------|--------|
| **HTML 코드** | 폴더에 그대로 두고 클로드로 수정 |
| **이미지** | `IMG/` 폴더에 넣고, 클로드에게 "이 이미지를 화면에 넣어줘" |
| **엑셀·CSV 데이터** | `data/` 폴더에 두기 (단, 아래 ⚠️ 주의사항 확인) |

파일을 추가·삭제·이동해도, 마지막에 **`배포.bat`만 누르면** 그대로 깃허브에 반영됩니다.

## 4. ⚠️ 꼭 지켜야 할 주의사항 (가장 중요!)

### 🔴 이 창고는 "공개(public)"입니다 — 올리는 모든 것이 인터넷에 공개됩니다
- **비밀번호 · 개인정보 · 대외비 회사자료 · 고객 데이터는 절대 올리지 마세요.**
- 한 번 올라가면 나중에 지워도 인터넷 어딘가에 남을 수 있습니다.
- 민감한 데이터를 저장해야 한다면, 파일로 올리지 말고 **로그인이 걸린 별도
  데이터베이스(서버)** 에 저장해야 합니다. (담당자에게 문의)

### 🔴 큰 파일은 올라가지 않습니다
- 한 파일이 **100MB를 넘으면 거부**됩니다(50MB만 넘어도 경고).
- 대용량 원본(큰 PPT, CAD 도면, 동영상 등)은 깃허브에 넣지 말고 따로 보관하세요.
- 웹에 쓸 이미지는 적당히 용량을 줄여서(수백 KB) 넣으세요.

### 🟡 편집 전에는 항상 `최신버전_받기.bat` 먼저
안 그러면 다른 팀원의 작업과 충돌할 수 있습니다.

### 🟡 "push 실패"가 떴다면
→ `최신버전_받기.bat`을 한 번 실행한 뒤, 다시 `배포.bat`을 누르세요. (대부분 자동 해결)

## 5. 클로드에게 일 시키는 요령

- **무엇을, 어느 파일에** 원하는지 구체적으로 말하기
  - 예: "index.html의 '문의하기' 버튼 색을 파란색으로 바꿔줘."
- 결과가 맘에 안 들면 그냥 다시 말하면 됩니다 — "글씨를 더 크게 해줘."
- 막히거나 오류가 나면, **화면의 오류 메시지를 그대로 복사해서** 클로드에게 보여주세요.
